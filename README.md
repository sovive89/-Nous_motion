# NØUS Motion

Biblioteca inicial de animações React + TypeScript, com CSS leve. Inclui seis estilos de loader, dez nomes de variantes de botão e quatro transições. Algumas variantes de botão ainda compartilham o mesmo efeito. **Protótipo não testado; não está pronto para produção.**

Instalação local: `npm install`. Verificação: `npm run check`. Build: `npm run build`.

Próximas tarefas para Codex: adicionar galeria/editor visual, presets JSON validados, testes, exports por subpath, build empacotado de biblioteca e medições de bundle. Não conectar a sistemas de produção ainda.
